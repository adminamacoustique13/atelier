# P2 — Seul un vrai `true` du vérificateur vaut accord

Base : a862a2f.

## Fait

1. `{"valide": true, ...}` vaut accord : `lire_verdict` rend `valide` à `True` (`objet["valide"] is True`).
2. Toute autre valeur vaut refus (`False`) : `"false"`, `"true"`, `"oui"`, `""`, `1`, `1.0`, `0`, `null`, `[]`, `[true]`, `{}`, `{"a": 1}`. Test paramétré, une valeur par cas.
3. Dans un tel refus, motif (inconnu ramené à `bacle`) et résumé (nettoyé) sont gardés comme pour un refus ordinaire : test dédié.
4. Verdict sans clé `valide` : inchangé (test de non-régression ajouté).
5. Rien d'autre ne change dans `lire_verdict` : `remarques` et `empeche` sont lus comme avant ; les 54 tests existants du fichier passent sans modification.

Échec constaté avant la correction (`"valide": "false"`) :
`FAILED tests/test_consignes.py::test_toute_autre_valeur_que_true_vaut_refus["false"]`
(8 échecs, 54 réussis avant correction ; 62 réussis après).
