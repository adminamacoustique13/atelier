# Relais P4 — Un fichier au nom accentué est reconnu dans son périmètre

Base vérifiée : `a862a2f`.

## 1. Fait

Cause : `ControlesGit.fichiers_modifies` lisait `git status --porcelain` sans `-z`. Git écrit alors
les noms spéciaux entre guillemets avec des codes octaux. Correction : la lecture passe en `-z` et
réutilise `_chemins_du_statut`, déjà employé pour la copie du vérificateur.

Preuve de l'échec avant correction (sur `a862a2f`, `controles.py` d'origine) :
`At index 0 diff: 'docs/\\303\\251t\\303\\251.md' != 'docs/été.md'`.
9 tests sur 15 échouaient avant la correction ; les 15 passent après.

1. **Critère 1** : `test_un_fichier_modifie_a_nom_special_est_dans_son_perimetre[docs/été.md-…]` :
   chaîne réelle `fichiers_modifies` puis `hors_perimetre`, aucun débord.
2. **Critère 2** : même test pour `notes de chantier.md`, `docs/dit "oui".md` et `docs/l'été.md` ;
   `test_un_fichier_nouveau_non_suivi_…`, `test_un_fichier_supprime_…` et
   `test_un_renommage_accentue_voit_l_ancien_et_le_nouveau_nom` (renommage indexé avec `git mv`).
3. **Critère 3** : `test_un_fichier_accentue_hors_perimetre_est_signale_sous_son_vrai_nom` : rendu
   `["docs/été.md"]`, et le fichier existe sous ce nom sur le disque.
4. **Critère 4** : les tests de nom spécial et le test de débord sont joués avec `core.quotePath`
   à `true` puis à `false` dans le dépôt d'essai. Avec `-z`, le réglage n'a plus d'effet.
5. **Critère 5** : `test_les_noms_ordinaires_gardent_la_meme_liste_dans_le_meme_ordre` compare à la
   sortie brute de `git status --porcelain` (modifié, supprimé, nouveau dans un dossier).

Contrôles : suite complète 1778 passés ; `ruff check .` : tout est vert.

## 5. Doutes et demandes

- Renommage : rendre aussi l'ancien nom est voulu par le critère 2 (« ancien et nouveau nom dans
  le périmètre ») et évite qu'une suppression hors périmètre passe inaperçue. C'est la seule
  différence avec l'ancienne liste ; elle ne touche que les renommages indexés. À confirmer.
- Test de renommage : git ne détecte un renommage que s'il est indexé (`git mv`).
