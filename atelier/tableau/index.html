    Fil du chantier

      Nouveau projet

      Ou reprendre un dépôt existant

      Le dépôt est récupéré dans le dossier des projets avec tes accès git habituels. Un dépôt privé demande que git soit déjà connecté à GitHub sur cet ordinateur.

      Dépôt en ligne

      Crée le dépôt vide sur GitHub, sans LISEZMOI ni licence, puis colle son adresse. L'Atelier y envoie tout ce qui est déjà enregistré, puis chaque tâche vérifiée, avec le cahier du chantier.
